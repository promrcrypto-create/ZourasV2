CC CHECKER BOT - COMPLETE PACKAGE
==================================

SETUP:
1. Open bot_complete.py
2. Set ADMIN_ID = your Telegram chat ID (integer, line 32)
3. Change WEB_SECRET = your web panel password (line 34)

INSTALL: pip install -r requirements.txt
RUN:     python bot_complete.py

Web Admin Panel: http://localhost:5000
Web Password:    admin (change WEB_SECRET in file)

NOTE: 10-second delay between each card check to avoid rate limiting.
